### What you will create
React Calculator

For this challenge, you will receive two numbers from an input element and add both numbers. Display the sum of these numbers on the same page.

![calculator](https://github.com/devtlv/studentsGitHub/blob/master/Javascript%20-%20Part%20Time/Week14/Day5/calculator_challenge.gif?raw=true)

---

### Instructions:

1. The functionalities:
- The user enters two numbers in two different inputs. When they click on the button “Add Them”, both numbers are added and the result is displayed on the page.

2. **Bonus**: In order to make a more universal calculator, add a `<select>` form, where the user will be able to select the type of operation: addition, subtraction, multiplication, or division.
